Resource Profile: Nigeria Alert Flag

Official URL: https://fhir-ig.digitalhealth.gov.ng/StructureDefinition/ng-flag Version: 0.0.0
Draft as of 2026-08-12 Computable Name: NgFlag
Other Identifiers: OID:2.16.840.1.113884.3.9944.1.42.28

Flag profile for prominent clinical, public-health, safety, or administrative alerts that require display, review, acknowledgement, or action.

Usages:

  • Examples for this Profile: Flag/NgFlag-001
  • CapabilityStatements using this Profile: Authoritative Nigeria Core Server Requirements, Nigeria Core General Hospital Requestor Capability, Nigeria Core General Hospital Responder Capability, Nigeria Core Tertiary Referral Requestor Capability and Nigeria Core Tertiary Referral Responder Capability

### Role

The **Nigeria Core Terminology Service** publishes, maintains, or provides
computational access to:

* `CodeSystem`;
* `ValueSet`;
* `ConceptMap`;
* `NamingSystem`, where applicable;
* national and program terminology; and
* adopted international terminology such as ICD-11, SNOMED CT, LOINC, ATC,
  and other approved systems where licensing permits.

### Responsibilities

The service may:

* publish governed terminology artefacts;
* validate codes and ValueSet membership;
* expand ValueSets;
* provide concept lookup;
* translate codes using governed `ConceptMap` resources;
* manage terminology versions and mappings; and
* support terminology validation during Nigeria Core conformance testing.

Supported operations may include:

`$lookup` | `$validate-code` | `$expand` | `$translate` | `$subsumes`

Availability **SHALL** be determined from the service `CapabilityStatement`.

### Conformance expectations

A Terminology Service **SHALL**:

* expose valid FHIR terminology resources;
* preserve canonical URLs and terminology identifiers;
* preserve relevant terminology versions;
* distinguish coding systems using governed identifiers;
* return FHIR-conformant responses;
* advertise only reliably supported terminology and operations; and
* provide an accurate `CapabilityStatement`.

It **SHALL NOT** silently substitute terminology versions where meaning or
validity could change.

Where local terminology is exchanged, the original code and coding system
**SHALL** be retained. Version information **SHOULD** be retained where
relevant, and governed mappings **SHOULD** use published `ConceptMap`
resources.

Mappings **SHOULD NOT** be treated as simple text substitutions. Where no valid
mapping exists, a service **SHOULD** report that no translation can be
determined rather than inventing a code.

Required terminology bindings defined by Nigeria Core profiles **SHALL** be
honoured.

### Governance and licensing

Terminology governance **SHOULD** address approval, versioning, retirement,
mapping, publication, correction, and stewardship.

National terminology **SHALL NOT** be locally modified while retaining the same
canonical identifier if the modification changes its governed meaning.

Implementers **SHALL** comply with applicable licensing and distribution
requirements for external terminologies.

### Relationships

The Terminology Service commonly supports the **Nigeria Core Requestor,
Responder, Registry Service,** and **Conformance and Sandbox Service**.

Facilities may consume shared national or subnational terminology services
rather than operating independent terminology servers."/>
